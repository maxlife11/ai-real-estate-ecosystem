## 🔄 Repository Workflow

1. **Development:** Create/modify files in workspace/
2. **Review:** Use file_read to check content
3. **Commit:** Use shell_execute for version control
5. **Push:** Use git commands to push to GitHub

## 🔧 Tools Available

- **shell_execute**: Execute shell commands
- **file_read**: Read file contents
- **file_write**: Write to files
- **memory_write**: Save to daily memory log
- **memory_get**: Retrieve past memories
